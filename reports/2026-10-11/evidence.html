Rule Evidence

Walk-forward test of the Decision Desk rules on 19 years of weekly prices, using only data available at each date.

Following the current rules has not beaten simply holding everything equally on this history: treat the calls as weak evidence.

Over 13 weeks, Accumulate names beat the average instrument by +0.2% and Avoid names by -0.1%. Accumulate minus Avoid t-statistic: -0.64 (non-overlapping samples; ≥2 is conventionally meaningful). No alternative rule passes the adoption test, so the live rule is unchanged.

How to use this

  • Supported rules earn more trust. If a stance fails in either half, size it down and lean harder on the checklist.
  • The weekly run re-tests these rules and logs any deterioration in the Improvement Log.

Limits of this test

  • Survivorship: today's instrument list is used for the whole period; past losers that left the list are missing.
  • Price returns in local currency, weekly closes, no trading costs, taxes or dividends.
  • The macro stress overlay (VIX risk budget) is not applied historically.
  • Instruments join the test when their history starts (for example XLC in 2018); each week the rule and the benchmark use the same set of instruments.
  • 36 instruments, 31,445 weekly observations from 2008-01-04: still a small sample for a market regime test.
  • Bad print excluded: RIO 2007-06-08 closed 0.35 between 36.84 and 39.16 (a unit error at the source; the raw file is kept as returned).
